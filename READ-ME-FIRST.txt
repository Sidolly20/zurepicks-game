ZurePicks - how to look at it
=============================

STEP 1 - See the design (no install, 10 seconds)
  Double-click  index.html  in this folder. It opens in Chrome.
  Click around: tabs, leagues, Log in (any email works), the Premium page, and /admin via the
  file  admin.html  (full dashboard with sample data).
  This is a PREVIEW with sample data. Nothing you click here is saved.

STEP 2 - Run the real thing on your PC (accounts, payments, premium that really locks)
  Open the folder  live-site
  Windows:  double-click  START-WINDOWS.bat
  Mac/Linux: run  START-MAC-LINUX.sh
  The first time it asks you to pick an admin email and password, then opens the site.
  You need Node.js 22 or newer (free, https://nodejs.org). The start file tells you if it is missing.
  Admin dashboard: http://localhost:3000/admin
  Optional sample games: in live-site run   node scripts/seed-demo.js

FOOTBALL DATA (free API)
  Get a free key at football-data.org. Put it in live-site/.env as FOOTBALL_DATA_KEY=yourkey
  (the START file also asks for it the first time) and restart. Then Admin > Games shows real
  fixtures to tap, and your tips turn green or red by themselves after full time.
  The preview already shows how this looks, with made-up fixtures.

STEP 3 - Put it online
  See live-site/README.md. The real site needs a host that runs Node.js and keeps a disk
  (a VPS, or Render/Railway with a persistent disk). Plain static hosting will NOT work
  for the real version, only the preview.
